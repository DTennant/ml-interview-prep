2.4 Debug 题

给一段训练代码，问 loss 为什么不降或者变成 NaN。常见埋的 bug：

  • 忘了 zero_grad()
  • F.cross_entropy 前面又做了一次 softmax
  • mask 方向反了
  • softmax / argmax 用错了维度
  • logits 和 labels flatten 的顺序不一致
  • 广播错误（(N,) 和 (N,1) 相减）
  • learning rate 太大 / 没有 warmup
  • 数据没有 shuffle
  • eval 时没调 model.eval() / 没加 no_grad
  • label 是 float 而不是 long
  • log(0) 导致 NaN
  • logging 时没 .item() 或 .detach()，导致内存泄漏

3.2 题库

A. 自我改进 / 自动化 ML research 的 agent 系统（最可能）

给一个任务和评估指标，系统自己提方案、跑实验、迭代。

  • 生成候选：LLM 提方案，加上历史尝试记录（memory），避免重复试一样的想法；历史记录怎么压缩后喂给 LLM
  • 搜索策略：tree search、进化、bandit（UCB / Thompson sampling）、successive halving。讲清楚怎么平衡探索和利用，以及预算怎么分配
  • 执行：每个候选在沙箱里跑，用容器隔离，设好超时、CPU/GPU/内存限制和网络隔离
  • 评估：分开 held-out 和 validation 数据，用多个 seed 处理噪声，结果要做显著性检验（paired bootstrap）
  • 风险：过拟合 eval、reward hacking（改 eval 代码、读 test label、硬编码答案）、eval 泄漏。对策：eval 放在 agent 碰不到的环境里，把 validation 和 test 分开，加 sanity check，定期人工抽查
  • 工程：结果缓存（按代码 + 配置 + seed 做 hash）、重复候选去重、失败重试，每个改进怎么来的、跑出什么结果都要能追溯和复现
  • 指标：单位成本带来的提升、多久找到最优解、改进能不能迁移到 held-out 任务
B. 大规模 agent eval / rollout 平台
  • 任务队列 + 调度（K8s / Ray），GPU 推理和 CPU 沙箱分开调度和扩缩容
  • LLM 调用走一个单独的推理服务（vLLM / SGLang），做 batching 和限流；用外部 API 时要处理 rate limit、重试和成本上限
  • 沙箱：镜像预构建 + 缓存，冷启动要快；多步工具调用时环境状态怎么管理；超时处理
  • 结果的确定性：固定 seed / temperature，记录模型版本和镜像 hash
  • 存储：结构化结果放数据库，完整 trajectory 放对象存储；能按任务、模型、版本查询和对比
  • 可观测性：dashboard、失败原因自动分类（环境错误 / 超时 / 模型错误）、成本监控
  • 规模估算示例：1 万个 rollout × 每个 10 分钟 ÷ 2 小时完成 → 大约 830 个并发沙箱
C. Agent RL 训练 pipeline
  • actor（vLLM 生成 rollout）和 learner（FSDP / Megatron 训练）分开部署；同步训练 vs 异步训练
  • 异步训练时数据 staleness 怎么处理：限制 policy 版本差、用 importance ratio 修正或 clip、丢掉太旧的数据
  • 权重同步到 actor：NCCL broadcast / 写到共享存储，多久同步一次
  • 奖励：verifier / 单测 / reward model；长任务奖励稀疏，credit assignment 怎么做；防 reward hacking
  • 多轮工具调用：环境放在单独的服务里；tool 返回的 token 要 mask 掉，不算进 loss
  • 长尾问题：有些 rollout 特别长，会拖慢整批 → 部分 rollout 先训、超时截断、动态 batch
  • 监控：reward 曲线、KL、entropy、response 长度、各种 clip 被触发的比例
D. LLM 推理服务
  • continuous batching；prefill 和 decode 两个阶段的特点不同（prefill 受算力限制，decode 受显存带宽限制）
  • KV cache 显存管理：PagedAttention、prefix caching（相同的 system prompt / few-shot 前缀可以复用）
  • throughput 和 latency 的取舍：batch size、TTFT（首 token 延迟）、TPOT（每个 token 的生成时间）
  • 多模型路由、量化、speculative decoding、tensor parallel
E. 其他可能的题
  • 训练数据 pipeline：爬取 → 去重（MinHash）→ 质量过滤 → 配比；怎么防止 eval 数据污染训练数据（n-gram overlap 检测）
  • 大规模分布式训练：DP / TP / PP / FSDP 分别切什么；怎么存 checkpoint，节点挂了怎么恢复
  • 实验追踪和复现系统：怎么管理配置、代码版本（git commit）、随机种子、数据版本和产出文件
  • reward model / verifier 服务，以及怎么防 reward hacking

01_mlp_numpy.py — MLP + softmax/CE + grad check (numpy) download · 
"""MLP from scratch in numpy: forward, backward, softmax-CE, gradient check, training.

Interview checklist:
- say shapes out loud: X (N, D), W1 (D, H), b1 (H,), W2 (H, C), b2 (C,)
- softmax must subtract the row max (log-sum-exp trick)
- dL/dlogits = (softmax - onehot) / N
- verify with a centered finite-difference gradient check
"""
import numpy as np


def softmax(z):
    z = z - z.max(axis=1, keepdims=True)          # numerical stability
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)


def log_softmax(z):
    z = z - z.max(axis=1, keepdims=True)
    return z - np.log(np.exp(z).sum(axis=1, keepdims=True))


def cross_entropy(logits, y):
    """logits (N, C), y (N,) int labels -> scalar mean loss"""
    N = logits.shape[0]
    return -log_softmax(logits)[np.arange(N), y].mean()


class MLP:
    def __init__(self, d_in, d_hidden, d_out, seed=0):
        rng = np.random.default_rng(seed)
        # He init for ReLU
        self.params = {
            "W1": rng.normal(0, np.sqrt(2.0 / d_in), (d_in, d_hidden)),
            "b1": np.zeros(d_hidden),
            "W2": rng.normal(0, np.sqrt(2.0 / d_hidden), (d_hidden, d_out)),
            "b2": np.zeros(d_out),
        }

    def forward(self, X):
        p = self.params
        h_pre = X @ p["W1"] + p["b1"]       # (N, H)
        h = np.maximum(h_pre, 0)            # ReLU
        logits = h @ p["W2"] + p["b2"]      # (N, C)
        self.cache = (X, h_pre, h)
        return logits

    def loss_and_grads(self, X, y):
        logits = self.forward(X)
        loss = cross_entropy(logits, y)
        X, h_pre, h = self.cache
        N = X.shape[0]
        p = self.params

        dlogits = softmax(logits)
        dlogits[np.arange(N), y] -= 1
        dlogits /= N                                  # (N, C)

        grads = {}
        grads["W2"] = h.T @ dlogits                   # (H, C)
        grads["b2"] = dlogits.sum(0)                  # (C,)
        dh = dlogits @ p["W2"].T                      # (N, H)
        dh_pre = dh * (h_pre > 0)                     # ReLU backward
        grads["W1"] = X.T @ dh_pre                    # (D, H)
        grads["b1"] = dh_pre.sum(0)
        return loss, grads


def grad_check(model, X, y, eps=1e-5, n_samples=20, seed=0):
    """Centered finite differences on random coordinates. Returns max relative error."""
    rng = np.random.default_rng(seed)
    _, grads = model.loss_and_grads(X, y)
    worst = 0.0
    for name, W in model.params.items():
        for _ in range(n_samples):
            idx = tuple(rng.integers(0, s) for s in W.shape)
            old = W[idx]
            W[idx] = old + eps
            lp, _ = model.loss_and_grads(X, y)
            W[idx] = old - eps
            lm, _ = model.loss_and_grads(X, y)
            W[idx] = old
            num = (lp - lm) / (2 * eps)
            ana = grads[name][idx]
            rel = abs(num - ana) / max(1e-8, abs(num) + abs(ana))
            worst = max(worst, rel)
    return worst


def make_spirals(n=300, k=3, seed=0):
    rng = np.random.default_rng(seed)
    X, y = [], []
    for c in range(k):
        r = np.linspace(0.0, 1, n)
        t = np.linspace(c * 4, (c + 1) * 4, n) + rng.normal(0, 0.2, n)
        X.append(np.c_[r * np.sin(t), r * np.cos(t)])
        y.append(np.full(n, c))
    return np.vstack(X), np.concatenate(y)


if __name__ == "__main__":
    X, y = make_spirals()
    model = MLP(2, 64, 3)
    # float64 + a random batch. Avoid points sitting exactly on the ReLU kink (e.g. X=0 with b1=0):
    # finite differences across the kink disagree with the analytic subgradient.
    idx = np.random.default_rng(1).choice(len(X), 16, replace=False)
    idx = idx[np.abs(X[idx]).sum(1) > 1e-3]
    err = grad_check(model, X[idx], y[idx])
    print(f"grad check max rel error: {err:.2e}")
    assert err < 1e-6

    lr = 1.0
    for step in range(2000):
        loss, grads = model.loss_and_grads(X, y)
        for k in model.params:
            model.params[k] -= lr * grads[k]
        if step % 500 == 0:
            print(f"step {step:4d} loss {loss:.4f}")
    acc = (model.forward(X).argmax(1) == y).mean()
    print(f"final loss {loss:.4f}, train acc {acc:.3f}")
    assert acc > 0.9
    print("OK")

"""LayerNorm / RMSNorm / BatchNorm forward + backward in numpy, checked numerically.

Interview checklist:
- LayerNorm normalises over the feature dim (per token); BatchNorm over the batch dim (per feature)
- BatchNorm keeps running stats for inference; LayerNorm behaves the same in train and eval
- LN backward compact form: dx = (1/sigma) * (g - mean(g) - xhat * mean(g * xhat)), g = dy * gamma
"""
import numpy as np


def layernorm_forward(x, gamma, beta, eps=1e-5):
    mu = x.mean(-1, keepdims=True)
    var = x.var(-1, keepdims=True)
    inv = 1.0 / np.sqrt(var + eps)
    xhat = (x - mu) * inv
    return xhat * gamma + beta, (xhat, inv, gamma)


def layernorm_backward(dy, cache):
    xhat, inv, gamma = cache
    dgamma = (dy * xhat).reshape(-1, xhat.shape[-1]).sum(0)
    dbeta = dy.reshape(-1, dy.shape[-1]).sum(0)
    g = dy * gamma
    dx = inv * (g - g.mean(-1, keepdims=True) - xhat * (g * xhat).mean(-1, keepdims=True))
    return dx, dgamma, dbeta


def rmsnorm_forward(x, gamma, eps=1e-6):
    rms = np.sqrt((x * x).mean(-1, keepdims=True) + eps)
    xhat = x / rms
    return xhat * gamma, (xhat, rms, gamma)


def rmsnorm_backward(dy, cache):
    xhat, rms, gamma = cache
    dgamma = (dy * xhat).reshape(-1, xhat.shape[-1]).sum(0)
    g = dy * gamma
    dx = (g - xhat * (g * xhat).mean(-1, keepdims=True)) / rms
    return dx, dgamma


class BatchNorm1d:
    def __init__(self, d, momentum=0.1, eps=1e-5):
        self.gamma, self.beta = np.ones(d), np.zeros(d)
        self.running_mean, self.running_var = np.zeros(d), np.ones(d)
        self.m, self.eps, self.training = momentum, eps, True

    def forward(self, x):                      # x: (N, D)
        if self.training:
            mu, var = x.mean(0), x.var(0)
            n = x.shape[0]
            self.running_mean = (1 - self.m) * self.running_mean + self.m * mu
            self.running_var = (1 - self.m) * self.running_var + self.m * var * n / (n - 1)  # unbiased
        else:
            mu, var = self.running_mean, self.running_var
        inv = 1 / np.sqrt(var + self.eps)
        xhat = (x - mu) * inv
        self.cache = (xhat, inv)
        return xhat * self.gamma + self.beta

    def backward(self, dy):
        xhat, inv = self.cache
        self.dgamma = (dy * xhat).sum(0)
        self.dbeta = dy.sum(0)
        g = dy * self.gamma
        return inv * (g - g.mean(0) - xhat * (g * xhat).mean(0))


def numgrad(f, x, eps=1e-6):

        x[i] = old - eps; fm = f()
        x[i] = old

"""Scaled dot-product + multi-head attention in numpy (causal + padding masks), checked against torch.

Interview checklist:
- scores = Q K^T / sqrt(d_head); mask BEFORE softmax with -inf (or a large negative number)
- causal mask: position i may attend to j <= i  -> np.triu(ones, k=1) are the masked entries
- shapes: x (B, T, D) -> q,k,v (B, H, T, Dh) with Dh = D // H
- complexity O(B * H * T^2 * Dh) time, O(B * H * T^2) memory for the score matrix
"""
import numpy as np


def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)


def scaled_dot_product_attention(q, k, v, mask=None):
    """q (..., Tq, d), k (..., Tk, d), v (..., Tk, dv); mask broadcastable to (..., Tq, Tk), True = keep."""
    d = q.shape[-1]
    scores = q @ np.swapaxes(k, -1, -2) / np.sqrt(d)
    if mask is not None:
        scores = np.where(mask, scores, -1e30)
    attn = softmax(scores, -1)
    return attn @ v, attn


def causal_mask(T):
    return np.tril(np.ones((T, T), dtype=bool))      # (T, T), True = allowed


def padding_mask(lengths, T):
    """lengths (B,) -> (B, 1, 1, T) mask over keys."""
    return (np.arange(T)[None, :] < np.asarray(lengths)[:, None])[:, None, None, :]


class MultiHeadAttention:
    def __init__(self, d_model, n_heads, seed=0):
        assert d_model % n_heads == 0
        rng = np.random.default_rng(seed)
        s = 1 / np.sqrt(d_model)
        self.Wq, self.Wk, self.Wv, self.Wo = (rng.normal(0, s, (d_model, d_model)) for _ in range(4))
        self.h, self.dh = n_heads, d_model // n_heads

    def split(self, x):          # (B, T, D) -> (B, H, T, Dh)
        B, T, _ = x.shape
        return x.reshape(B, T, self.h, self.dh).transpose(0, 2, 1, 3)

    def merge(self, x):          # (B, H, T, Dh) -> (B, T, D)
        B, H, T, Dh = x.shape
        return x.transpose(0, 2, 1, 3).reshape(B, T, H * Dh)

    def __call__(self, x, mask=None):
        q, k, v = self.split(x @ self.Wq), self.split(x @ self.Wk), self.split(x @ self.Wv)
        out, attn = scaled_dot_product_attention(q, k, v, mask)
        return self.merge(out) @ self.Wo, attn

"""Minimal GPT in PyTorch: RoPE, RMSNorm, causal MHA with KV cache, SwiGLU MLP, AdamW + warmup/cosine,
grad clipping, grad accumulation, and sampling (temperature / top-k / top-p).

Trains a char-level model on a tiny repeated text and checks:
  1) loss goes down
  2) KV-cache generation == full-recompute generation (greedy)

Interview checklist:
- pre-norm residual: x = x + attn(norm(x)); x = x + mlp(norm(x))
- weight tying between token embedding and lm_head
- AdamW: decoupled weight decay; common choice: decay only >=2D weights (matmuls, embeddings), not norms/biases
- KV cache: per layer store k,v of shape (B, H, T_past, Dh); new token attends to all of them; no mask needed for 1 query
- per-token cost with cache: O(T * D) attention instead of O(T^2 * D)
"""
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)


class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.w, self.eps = nn.Parameter(torch.ones(d)), eps

    def forward(self, x):
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps) * self.w


def rope_cache(T, dh, base=10000.0):
    inv = 1.0 / base ** (torch.arange(0, dh, 2).float() / dh)       # (dh/2,)
    ang = torch.outer(torch.arange(T).float(), inv)                  # (T, dh/2)
    return ang.cos(), ang.sin()


def apply_rope(x, cos, sin):
    """x (B, H, T, dh); rotate pairs (x0,x1),(x2,x3),..."""
    x1, x2 = x[..., 0::2], x[..., 1::2]
    out = torch.stack([x1 * cos - x2 * sin, x1 * sin + x2 * cos], dim=-1)
    return out.flatten(-2)


class Attention(nn.Module):
    def __init__(self, d, h):
        super().__init__()
        self.h, self.dh = h, d // h
        self.qkv = nn.Linear(d, 3 * d, bias=False)
        self.o = nn.Linear(d, d, bias=False)

    def forward(self, x, cos, sin, cache=None):
        B, T, D = x.shape
        q, k, v = self.qkv(x).view(B, T, 3, self.h, self.dh).permute(2, 0, 3, 1, 4)  # each (B,H,T,dh)
        q, k = apply_rope(q, cos, sin), apply_rope(k, cos, sin)
        if cache is not None:
            if "k" in cache:
                k = torch.cat([cache["k"], k], dim=2)
                v = torch.cat([cache["v"], v], dim=2)
            cache["k"], cache["v"] = k, v
        Tk = k.shape[2]
        # causal mask that also works when T < Tk (decoding with cache)
        mask = torch.ones(T, Tk, dtype=torch.bool, device=x.device).tril(diagonal=Tk - T)
        att = (q @ k.transpose(-1, -2)) / math.sqrt(self.dh)
        att = att.masked_fill(~mask, float("-inf")).softmax(-1)
        y = (att @ v).transpose(1, 2).reshape(B, T, D)
        return self.o(y)


class SwiGLU(nn.Module):
    def __init__(self, d, hidden):
        super().__init__()
        self.w1, self.w3 = nn.Linear(d, hidden, bias=False), nn.Linear(d, hidden, bias=False)
        self.w2 = nn.Linear(hidden, d, bias=False)

    def forward(self, x):
        return self.w2(F.silu(self.w1(x)) * self.w3(x))


class Block(nn.Module):
    def __init__(self, d, h):
        super().__init__()
        self.n1, self.attn = RMSNorm(d), Attention(d, h)
        self.n2, self.mlp = RMSNorm(d), SwiGLU(d, 4 * d)

    def forward(self, x, cos, sin, cache=None):
        x = x + self.attn(self.n1(x), cos, sin, cache)
        return x + self.mlp(self.n2(x))


class GPT(nn.Module):
    def __init__(self, vocab, d=64, h=4, L=2, max_T=256):
        super().__init__()
        self.emb = nn.Embedding(vocab, d)
        self.blocks = nn.ModuleList(Block(d, h) for _ in range(L))
        self.norm = RMSNorm(d)
        self.head = nn.Linear(d, vocab, bias=False)
        self.head.weight = self.emb.weight                     # weight tying
        cos, sin = rope_cache(max_T, d // h)
        self.register_buffer("cos", cos, persistent=False)
        self.register_buffer("sin", sin, persistent=False)

    def forward(self, idx, caches=None, pos=0):
        T = idx.shape[1]
        cos, sin = self.cos[pos:pos + T], self.sin[pos:pos + T]
        x = self.emb(idx)
        for i, b in enumerate(self.blocks):
            x = b(x, cos, sin, None if caches is None else caches[i])
        return self.head(self.norm(x))


def sample_next(logits, temperature=1.0, top_k=None, top_p=None):
    """logits (B, V) -> (B, 1)."""
    if temperature == 0:
        return logits.argmax(-1, keepdim=True)
    logits = logits / temperature
    if top_k is not None:
        kth = torch.topk(logits, top_k, dim=-1).values[..., -1:]
        logits = logits.masked_fill(logits < kth, float("-inf"))
    if top_p is not None:
        sorted_logits, sorted_idx = logits.sort(-1, descending=True)
        probs = sorted_logits.softmax(-1)
        cum = probs.cumsum(-1)
        remove = cum - probs > top_p                     # keep the smallest prefix with mass >= top_p
        sorted_logits = sorted_logits.masked_fill(remove, float("-inf"))
        logits = torch.full_like(logits, float("-inf")).scatter(-1, sorted_idx, sorted_logits)
    return torch.multinomial(logits.softmax(-1), 1)


@torch.no_grad()
def generate_naive(model, idx, n, **kw):
    for _ in range(n):
        logits = model(idx)[:, -1]
        idx = torch.cat([idx, sample_next(logits, **kw)], 1)
    return idx


@torch.no_grad()
def generate_kv(model, idx, n, **kw):
    caches = [{} for _ in model.blocks]
    logits = model(idx, caches, pos=0)[:, -1]            # prefill
    out = idx
    for _ in range(n):
        nxt = sample_next(logits, **kw)
        out = torch.cat([out, nxt], 1)
        logits = model(nxt, caches, pos=out.shape[1] - 1)[:, -1]   # decode one token
    return out


def lr_at(step, max_lr, warmup, total, min_lr_ratio=0.1):
    if step < warmup:
        return max_lr * (step + 1) / warmup
    p = (step - warmup) / max(1, total - warmup)
    return max_lr * (min_lr_ratio + (1 - min_lr_ratio) * 0.5 * (1 + math.cos(math.pi * p)))

    return torch.optim.AdamW([{"params": decay, "weight_decay": wd},

05_optimizers_numpy.py — SGD / Adam / AdamW from scratch (numpy, vs torch) download · 
"""SGD+momentum, Adam, AdamW from scratch; checked against torch.optim on the same problem.

Interview checklist:
- Adam: m = b1 m + (1-b1) g ; v = b2 v + (1-b2) g^2 ; bias-correct mhat = m/(1-b1^t), vhat = v/(1-b2^t)
- update: p -= lr * mhat / (sqrt(vhat) + eps)
- L2 in Adam (add wd*p to g) != AdamW (p -= lr*wd*p separately): with Adam the decay gets rescaled by 1/sqrt(v)
- torch SGD momentum: buf = mu*buf + g ; p -= lr*buf (no dampening by default)
"""
import numpy as np


class SGD:
    def __init__(self, params, lr, momentum=0.0, weight_decay=0.0):
        self.p, self.lr, self.mu, self.wd = params, lr, momentum, weight_decay
        self.buf = [np.zeros_like(x) for x in params]

    def step(self, grads):
        for p, g, b in zip(self.p, grads, self.buf):
            g = g + self.wd * p
            b *= self.mu
            b += g
            p -= self.lr * b


class Adam:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8, weight_decay=0.0, decoupled=False):
        self.p, self.lr, (self.b1, self.b2), self.eps = params, lr, betas, eps
        self.wd, self.decoupled, self.t = weight_decay, decoupled, 0
        self.m = [np.zeros_like(x) for x in params]
        self.v = [np.zeros_like(x) for x in params]

    def step(self, grads):
        self.t += 1
        for p, g, m, v in zip(self.p, grads, self.m, self.v):
            if self.decoupled:
                p -= self.lr * self.wd * p            # AdamW
            else:
                g = g + self.wd * p                   # L2 (Adam)
            m[:] = self.b1 * m + (1 - self.b1) * g
            v[:] = self.b2 * v + (1 - self.b2) * g * g
            mhat = m / (1 - self.b1 ** self.t)
            vhat = v / (1 - self.b2 ** self.t)
            p -= self.lr * mhat / (np.sqrt(vhat) + self.eps)


def AdamW(params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8, weight_decay=1e-2):
    return Adam(params, lr, betas, eps, weight_decay, decoupled=True)


def quad_grad(w, A, b):
    """loss = 0.5 w^T A w - b^T w -> grad = A w - b"""
    return A @ w - b

07_classic_ml_numpy.py — Classic ML: logreg, k-means, PCA, kNN, conv2d im2col (numpy) download · 
"""Classic ML from scratch: logistic regression (GD), k-means (k-means++ init), PCA via SVD, kNN, conv2d (im2col).

Interview checklist:
- logistic regression grad: X^T (sigmoid(Xw) - y) / N ; use a stable sigmoid / logaddexp for the loss
- k-means: alternate assign / update; handle empty clusters; k-means++ init; objective is non-increasing
- PCA: center X, SVD X = U S V^T, components = V[:k], explained variance = S^2 / (N-1)
- conv2d via im2col: (N,C,H,W) -> patches (N*Ho*Wo, C*kh*kw) @ W.reshape(F, -1).T
"""
import numpy as np


def sigmoid(z):
    return np.where(z >= 0, 1 / (1 + np.exp(-np.abs(z))), np.exp(-np.abs(z)) / (1 + np.exp(-np.abs(z))))


def logreg_fit(X, y, lr=0.5, steps=1000, l2=0.0):
    Xb = np.c_[X, np.ones(len(X))]
    w = np.zeros(Xb.shape[1])
    for _ in range(steps):
        z = Xb @ w
        grad = Xb.T @ (sigmoid(z) - y) / len(y) + l2 * np.r_[w[:-1], 0]
        w -= lr * grad
    loss = np.mean(np.logaddexp(0, z) - y * z)          # stable BCE
    return w, loss


def kmeans_single(X, k, iters=100, seed=0):
    rng = np.random.default_rng(seed)
    C = [X[rng.integers(len(X))]]
    for _ in range(1, k):                                 # k-means++
        d2 = np.min(((X[:, None] - np.array(C)[None]) ** 2).sum(-1), 1)
        C.append(X[rng.choice(len(X), p=d2 / d2.sum())])
    C = np.array(C)
    prev = np.inf
    for _ in range(iters):
        d2 = ((X[:, None] - C[None]) ** 2).sum(-1)       # (N, k)
        a = d2.argmin(1)
        obj = d2[np.arange(len(X)), a].sum()
        assert obj <= prev + 1e-9
        for j in range(k):
            C[j] = X[a == j].mean(0) if np.any(a == j) else X[rng.integers(len(X))]
        if prev - obj < 1e-10:
            break
        prev = obj
    return C, a, obj


def kmeans(X, k, n_init=5, seed=0):
    """k-means only finds a local optimum -> run several inits and keep the lowest objective."""
    return min((kmeans_single(X, k, seed=seed + i) for i in range(n_init)), key=lambda r: r[2])


def pca(X, k):
    mu = X.mean(0)
    U, S, Vt = np.linalg.svd(X - mu, full_matrices=False)
    comps = Vt[:k]
    var = S ** 2 / (len(X) - 1)
    return comps, (X - mu) @ comps.T, var[:k] / var.sum()


def knn_predict(Xtr, ytr, Xte, k=5):
    # ||a-b||^2 = |a|^2 + |b|^2 - 2ab, vectorised
    d2 = (Xte ** 2).sum(1)[:, None] + (Xtr ** 2).sum(1)[None] - 2 * Xte @ Xtr.T
    nn_idx = np.argpartition(d2, k, axis=1)[:, :k]
    votes = ytr[nn_idx]
    return np.array([np.bincount(v).argmax() for v in votes])


def conv2d_im2col(x, W, b, stride=1, pad=0):
    N, C, H, Wd = x.shape
    F, _, kh, kw = W.shape
    x = np.pad(x, ((0, 0), (0, 0), (pad, pad), (pad, pad)))
    Ho, Wo = (H + 2 * pad - kh) // stride + 1, (Wd + 2 * pad - kw) // stride + 1
    cols = np.empty((N, Ho, Wo, C, kh, kw))
    for i in range(kh):
        for j in range(kw):
            cols[:, :, :, :, i, j] = x[:, :, i:i + stride * Ho:stride, j:j + stride * Wo:stride].transpose(0, 2, 3, 1)
    out = cols.reshape(N * Ho * Wo, -1) @ W.reshape(F, -1).T + b
    return out.reshape(N, Ho, Wo, F).transpose(0, 3, 1, 2)

08_rl_losses_torch.py — RL losses: REINFORCE, GAE, PPO, GRPO, k3 KL (torch) download · 
"""RL for LLM agents: REINFORCE with baseline, GAE, PPO clipped loss, GRPO group advantage, k3 KL estimator.
Plus a runnable sanity check: REINFORCE learns a 5-armed bandit.

Interview checklist:
- policy gradient: grad E[R] = E[grad log pi(a|s) * A]; baseline reduces variance, keeps it unbiased
- GAE: delta_t = r_t + gamma V(s_{t+1}) (1-done) - V(s_t); A_t = delta_t + gamma*lam*(1-done) A_{t+1}
- PPO: ratio = exp(logp_new - logp_old); L = -min(ratio*A, clip(ratio, 1-eps, 1+eps)*A)
- GRPO: sample G responses per prompt; A_i = (r_i - mean(r)) / (std(r) + eps); no value net
- token-level masking: only response tokens count; average over valid tokens (be explicit about seq vs token mean)
- KL to reference: k3 = exp(ref - logp) - (ref - logp) - 1  (unbiased, always >= 0)
"""
import torch


def reinforce_loss(logp, returns, baseline=None):
    adv = returns - (returns.mean() if baseline is None else baseline)
    return -(logp * adv.detach()).mean()


def gae(rewards, values, dones, gamma=0.99, lam=0.95):
    """rewards, dones: (T,), values: (T+1,) incl. bootstrap value. Returns advantages (T,), returns (T,)."""
    T = rewards.shape[0]
    adv = torch.zeros(T)
    last = 0.0
    for t in reversed(range(T)):
        nonterm = 1.0 - dones[t]
        delta = rewards[t] + gamma * values[t + 1] * nonterm - values[t]
        last = delta + gamma * lam * nonterm * last
        adv[t] = last
    return adv, adv + values[:-1]


def ppo_loss(logp_new, logp_old, adv, mask, clip_eps=0.2):
    """all (B, T); mask = 1 for response tokens."""
    ratio = torch.exp(logp_new - logp_old)
    unclipped = ratio * adv
    clipped = ratio.clamp(1 - clip_eps, 1 + clip_eps) * adv
    per_tok = -torch.min(unclipped, clipped)
    return (per_tok * mask).sum() / mask.sum()


def grpo_advantages(rewards, group_size, eps=1e-6):
    """rewards (B*G,) ordered by prompt -> advantages (B*G,)."""
    r = rewards.view(-1, group_size)
    return ((r - r.mean(1, keepdim=True)) / (r.std(1, keepdim=True) + eps)).view(-1)


def k3_kl(logp, logp_ref):
    d = logp_ref - logp
    return torch.exp(d) - d - 1


def token_logprobs(logits, tokens):
    """logits (B, T, V), tokens (B, T) -> log pi(token) (B, T)"""
    return torch.log_softmax(logits, -1).gather(-1, tokens.unsqueeze(-1)).squeeze(-1)

"""Small coding pieces that tend to show up inside a system design round.

1. Async worker pool with timeout + retry + exponential backoff (rollout / eval runner)
2. UCB1 bandit for allocating budget across candidate ideas
3. Paired bootstrap / significance test: is candidate B really better than A?
4. Content-hash cache + dedup for experiment results
5. Successive halving (budgeted search over candidates)

# ---------- 1. worker pool ----------
async def run_with_retry(fn, item, timeout, retries=3, base_delay=0.05):
    for attempt in range(retries + 1):
        try:
            return {"item": item, "ok": True, "result": await asyncio.wait_for(fn(item), timeout)}
        except Exception as e:  # noqa: BLE001  (TimeoutError included)
            if attempt == retries:
                return {"item": item, "ok": False, "error": type(e).__name__}
            await asyncio.sleep(base_delay * 2 ** attempt * (1 + random.random()))   # backoff + jitter


async def worker_pool(fn, items, concurrency=8, timeout=1.0, retries=3):
    sem = asyncio.Semaphore(concurrency)

    async def guarded(it):
        async with sem:
            return await run_with_retry(fn, it, timeout, retries)

    return await asyncio.gather(*(guarded(i) for i in items))


# ---------- 2. UCB1 ----------
class UCB1:
    def __init__(self, n_arms, c=2.0):
        self.n, self.s, self.c, self.t = [0] * n_arms, [0.0] * n_arms, c, 0

    def select(self):
        self.t += 1
        for i, n in enumerate(self.n):
            if n == 0:
                return i
        return max(range(len(self.n)),
                   key=lambda i: self.s[i] / self.n[i] + math.sqrt(self.c * math.log(self.t) / self.n[i]))

    def update(self, i, reward):
        self.n[i] += 1
        self.s[i] += reward


# ---------- 3. paired bootstrap ----------
def paired_bootstrap(scores_a, scores_b, n_boot=5000, seed=0):
    """Per-task scores of A and B on the same tasks. Returns (mean diff, 95% CI, p(B<=A))."""
    rng = random.Random(seed)
    d = [b - a for a, b in zip(scores_a, scores_b)]
    n = len(d)
    means = sorted(sum(d[rng.randrange(n)] for _ in range(n)) / n for _ in range(n_boot))
    p = sum(m <= 0 for m in means) / n_boot
    return sum(d) / n, (means[int(.025 * n_boot)], means[int(.975 * n_boot)]), p


# ---------- 4. cache ----------
class ResultCache:
    def __init__(self):
        self.store = {}

    @staticmethod
    def key(code: str, config: dict, seed: int) -> str:
        blob = json.dumps({"code": code, "config": config, "seed": seed}, sort_keys=True)
        return hashlib.sha256(blob.encode()).hexdigest()

    def get_or_run(self, code, config, seed, run):
        k = self.key(code, config, seed)
        if k not in self.store:
            self.store[k] = run()
        return self.store[k]


# ---------- 5. successive halving ----------
def successive_halving(candidates, evaluate, budget0=1, eta=2):
    """evaluate(candidate, budget) -> score (higher better)."""
    pool, budget = list(candidates), budget0
    while len(pool) > 1:
        scored = sorted(pool, key=lambda c: evaluate(c, budget), reverse=True)
        pool, budget = scored[:max(1, len(pool) // eta)], budget * eta
    return pool[0]
